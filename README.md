  # Heterogeneous Effects of Local Government Financing Channels on Industrial Structure: Evidence from Provincial-Level Panel Data in China

   This project examines how LGFV debt versus statutory local debt shapes provincial industrial structure in China. It uses a two-way fixed-effects panel model, a data-driven industrial structure index with trained sector weights, a log debt-ratio DSI, and robustness checks using alternative measures, exclusions, and lags

### The preprint of this study has now been published on OSF. The link is: https://doi.org/10.31235/osf.io/3waq5_v1
